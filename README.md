**Picando y Tomando - Sistema de Gestión para Tienda y Bar**

Sistema en desarrollo para la gestión de una tienda de barrio tipo bar, donde se venden productos como licores, bebidas, dulces, papel, productos del hogar y además es un espacio social con música.

El sistema permite administrar mesas, pedidos y clientes de forma sencilla.

**Descripción**

"Picando y Tomando" es una aplicación en desarrollo para organizar el funcionamiento de un local mixto (tienda + bar), donde los clientes pueden consumir productos en mesas mientras disfrutan de música en el lugar.

El sistema busca digitalizar el control de mesas y pedidos del negocio.

-Tecnologías usadas

  - HTML5
  - CSS / SCSS (Sass)
  - JavaScript (DOM dinámico)
  - Node.js
  - Mysql
  - Git / GitHub

**En desarrollo futuro:**
- Node.js + Express
- MySQL
- Electron (app de escritorio)



## Funcionalidades actuales

- ✔ 7 mesas creadas por defecto
- ✔ Agregar nuevas mesas dinámicamente
- ✔ Botón "+" para crear mesas adicionales
- ✔ Campo para nombre del producto para la mesa
- ✔ Área para pedidos por mesa
- ✔ Interfaz tipo sistema POS

## Tipo de negocio

Este sistema está diseñado para un negocio mixto:

-  Venta de licores y bebidas
- Dulces y snacks
- Productos básicos del hogar (papel, etc.)
- Ambiente social con música
- Consumo en mesas dentro del local
